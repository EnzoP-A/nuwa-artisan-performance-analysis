# Sales Performance Analysis

## Overview

This project analyzes sales data using Microsoft Excel to identify key performance trends and build a clear business performance dashboard.

The objective is to transform raw sales data into actionable business insights through data cleaning, KPI analysis, pivot tables and visualization.

## Business Questions

The analysis will focus on questions such as:

- Which products generate the most revenue?
- Which sales categories perform best?
- How does performance evolve over time?
- Which segments contribute the most to total sales?
- What business insights can be derived from the data?

## Tools

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel formulas
- Data segmentation
- Dashboarding

## Key Skills Demonstrated
